## 已实现

真实数据库目录 → 下单 CREATED → 按 ORD 查询 → 自动用 order.id 确认 → 拣货 → 发货（唯一运单）→ 揽收/签收；追踪可查。库存及日志由事务处理，不靠前端改文字。身份仅用于隔离教学演示，不是真实认证。

## 接续时不得破坏

1. 钱为整数分，历史单价为快照。
2. 创建不占库存；确认减少可用库存并写 ORDER_CONFIRM；发货不再次扣减、不写库存流水。
3. 重复确认返回 409，无二次扣减；重复发货返回 409 且只有一张运单；失败不得保留部分库存/流水/状态/运单/事件。
4. orderNumber、内部 id、trackingNumber 区分；状态路由与追踪用内部 id，发货用 ORD 单号。
5. 先审当前团队仓库差异，本包不是授权覆盖别人的新代码。
6. 不清旧库，不无脑升级依赖，不把演示身份当正式登录。
7. 状态路由必须保留 X-Demo-User-Email 与 STAFF 校验；禁止迁入“省略身份即可操作”的逻辑。
