# Increment definitions

An increment is a defined body of development work assessed against an exit criterion; inclusion in a repository or CI run records integration, not external user delivery. The rows reconstruct scope and criteria from repository artefacts where no contemporaneous definition is preserved. Dates are those recorded by the cited artefacts or commits; a claimed earlier planning date is not established by these sources.
