# 已知限制与风险（v0.4.2）

本文件如实记录仍未满足或有条件满足的事项；不能把“未复现”写成“无风险”。

1. **仅本机演示，不是生产系统。** 没有 TLS 终止、反向代理、备份、监控与公网加固；HTTPS 相关行为（Cookie `Secure`）只在代码路径上实现，未做真实证书部署验证。
2. **依赖风险未清零（2026-11-01 实测）。** `npm audit --json` 为 **3 high + 16 moderate**，`npm audit --omit=dev --json` 仍有 **3 high**。原始输出分别为交付包 `evidence/audit.json` 与 `evidence/audit-omit-dev.json`，命令/退出码/汇总见 `evidence/audit-summary.json` 和 `test-logs/`。high 链为 `prisma → @prisma/config → deepmerge-ts`（GHSA-ggr8-5vv4-36mx，递归对象图合并可能耗尽调用栈），三个包计数源自同一依赖链，不能等同三个独立根漏洞。`prisma` 在当前 dependencies 中，因此 omit=dev 不会排除这条链；撤回“仅 dev/非运行时，所以运行环境无风险”的笼统表述。当前未证明业务 HTTP 路径可利用，也未证明不可利用。16 moderate 是 ESLint 相关包及 minimatch 链的包级计数，原始 advisory 为 GHSA-g3hv-75wg-m249（globparts amplification 潜在拒绝服务）；该 moderate 链在本次 omit=dev 输出中未出现，不代表所有依赖风险消失。扫描建议涉及 Prisma 7 等跨主版本变更，部分建议甚至会改变现有 ESLint/Next 版本组合；本轮保留锁定依赖，不运行 `npm audit fix --force`、不盲目 override、不伪称已修复。
3. **SQLite 单写者。** 并发写冲突会有界重试，最终可能返回 503；不承诺企业级吞吐。竞争测试覆盖“同单重复确认/取消/发货、两单抢同一库存、取消与拣货竞争”，但没有压测高并发。
4. **登录限流是进程内计数。** 多进程/重启会清零；演示级别，不承担防撞库职责。限流按规范化邮箱统计，忽略客户端代理来源头；轮换 X-Forwarded-For 仍受同一账户限制。未实现跨进程限流或独立的全局请求限速。
5. **会话管理。** 8 小时固定过期，不滑动续期；修改密码/删除用户不会主动踢掉已有会话（本项目未实现改密）。会话表无定期清理任务，过期行在下次访问该令牌时删除。
6. **CSRF 采用服务端令牌 + Origin 校验**，未实现双重提交 Cookie；跨站嵌入场景未测试。
7. **金额与支付。** 只有整数分与下单快照，没有支付、退款、对账；“已签收订单金额/非取消订单金额”不是收入口径。
8. **物流为模拟。** 承运商为 1–40 字自由文本；揽收/签收由员工手动触发，不代表真实承运商回传或 GPS。
9. **报表口径。** 按订单 `createdAt` 归属 GMT+8 自然日；库存指标为当前快照，不随日期过滤；CSV 只导出订单维度，不含商品明细。
10. **编号。** 订单 `ORD-YYYYMMDD-XXXX` 与运单 `LG-YYYYMMDD-XXXXXX` 采用 UTC 日历日编号、界面 GMT+8 展示，夜间会跨日期；每日上限分别为 9999 / 999999，耗尽返回可读 503。
11. **创建幂等。** 前端防重复点击、网络未知时引导去“我的订单”核对，但没有服务端幂等键；极端重复提交仍可能创建两张单。
12. **seed 是破坏性操作。** 必须显式 `RESET_DEMO_DATA=YES`，只用于全新/可丢弃库；不会在默认启动时清库。证据入口也要求调用者显式确认，并且仅在独立临时源码副本中初始化新库，原项目库不参与。
13. **演示口令。** 默认 `Demo1234!` 仅用于本地演示，可用 `DEMO_PASSWORD` 覆盖；交付包不含真实 secret。
14. **测试范围。** 浏览器验收在 Chromium 单引擎完成；未做 Safari/Firefox、真实读屏器、WCAG 认证或长期可用性（08:00–24:00）测试。可访问性只做了可见 label、键盘焦点、非纯颜色区分等基础检查。
15. **Prisma CLI 的环境变量坑。** 若 shell 设置了 `RUST_LOG`，Prisma 在数据库文件尚不存在时会报空 `Schema engine error`（其 stderr 解析假定首行是 banner）。本地执行 Prisma 命令前 `unset RUST_LOG`，或先 `touch prisma/dev.db`；CI 不受影响。
16. **未实现（明确不在本轮范围）。** 公开注册、找回密码、OAuth/MFA、用户管理、真实支付/退款、真实承运商 API、邮件/短信/推送、多仓多租户、采购、退货、移动原生 App、Docker/公网托管、任何新的课程文档。
