# 已知限制与风险

1. **仅本机演示。** X-Demo-User-Email 可被冒用，GET 不检查订单所有权，POST 客户邮箱也不是认证。不能认定真实认证/生产安全通过。
2. **npm audit 3 项 high 未修复。** prisma → @prisma/config → deepmerge-ts；GHSA-ggr8-5vv4-36mx，递归图合并可能耗尽调用栈。审计建议跨主版本到 Prisma 7.10.1，未盲目采纳；实际利用条件/风险接受仍需进一步评估。不是 3 个彼此独立的业务漏洞，也不能忽略。
3. **基线局限。** 未连接团队 GitHub，不知道仓库是否有其他新修改；不得整包覆盖。
4. **并非全项目完成。** 创建/查询/确认、拣货、发货及追踪已实现；揽收/签收为员工触发的本地模拟。取消、独立预警页、补货、通知、报表、客户自助追踪门户和真实认证未实现。范围详见 closure/scope-and-srs-addendum.md。
5. **编号。** 当前沿用 UTC 日历日，显示时间为 GMT+8。每日四位号最大 9999；编号争用有限重试，非高吞吐承诺。
6. **创建幂等。** 浏览器防连点不等于跨客户端请求幂等；未知网络结果不要盲目重发。尚无创建幂等键、订单列表或客户历史订单入口。
7. **seed 破坏性。** 只允许在全新/可丢弃库显式确认后执行，已有库合并不应重置或 seed。
8. **未做的验证。** 无真实用户验收、全浏览器矩阵、负载/长期可用性测试；未据此宣布 NFR 全通过。
9. **历史材料。** 原 10/26 响应样例/验证稿是历史证据，不能用于证明新库存在相同订单。SKU008 历史验收 fixture 与当前 seed 不同，未做预警验收。
10. **v0.3 追踪无鉴权。** GET `/api/v1/orders/{id}/tracking` 与 GET `/api/v1/orders` 同姿态：不要求演示身份，也无对象级所有权校验；错误 id 只返回 404。不能用于真实客户数据。
11. **承运商为自由文本。** POST `/api/v1/shipments` 的 carrier 仅校验 1–40 字，未接承运商主数据/字典。
12. **取消与通知仍未实现。** 本轮只做拣货/发货/追踪；`to=CANCELLED` 仍返回 400。CONFIRMED 取消的流水 reason 已预定义 `ORDER_CANCEL_RELEASE`，但接口未实现。
13. **运单号按 UTC 日历日 6 位序号。** 每日上限 999999；并发冲突有限重试，非高吞吐承诺。
