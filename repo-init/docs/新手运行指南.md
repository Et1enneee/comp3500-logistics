# 新手运行指南（按顺序做，5 步就够）

## 第 0 步：装软件（只第一次，约 10 分钟）
1. 浏览器打开 https://nodejs.org
2. 点绿色大按钮「LTS」，下载后一路 Next 装完（什么都别改）
3. 打开终端（Mac 搜 Terminal；Windows 搜 cmd），输入：node -v 回车
4. 出现数字（如 v20.9.0）＝装好了

## 第 1 步：拿项目
1. 把「第一周代码包」解压出 logistics-system 文件夹，放桌面
2. 终端输入 `cd` 和空格，把文件夹拖进终端窗口（自动变路径），回车

## 第 2 步：建项目骨架
一行一行输入，每条回车（问问题就一路回车用默认）：
`npx create-next-app@latest . --typescript --eslint --app --yes`
`npm i prisma @prisma/client`
`npm i -D tsx vitest`

## 第 3 步：放现成文件（照搬，不改）
代码包里这些文件复制到项目同位置（覆盖同名）：
- prisma/schema.prisma（覆盖）；prisma/seed.ts（新增）
- lib/prisma.ts、lib/constants.ts、lib/constants.test.ts（新增，没有 lib 文件夹就新建）
- app/page.tsx（覆盖）；app/api/v1/orders/route.ts（新增，没有的文件夹一层层新建）
- 把 package-json.additions.json 里两段，加进项目 package.json（scripts 处和 prisma 处）

## 第 4 步：建数据库＋灌演示数据
`npx prisma migrate dev --name init`
`npx prisma db seed`

## 第 5 步：启动网站
1. `npm run dev` 回车，窗口别关
2. Chrome 地址栏输入 http://localhost:3000
3. 看到「物流管理系统 · 演示版」＝成功

## 跑测试
新开终端（重做第 1 步 cd），输入 `npm test`，看到 9 个 passed。

## 报错怎么办
截图发群 → 组长贴给 AI 参谋部 → 拿到下一步照着做。
