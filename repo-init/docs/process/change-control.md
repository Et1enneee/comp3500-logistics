# 变更控制 · Change Control (v0)

## 冻结前（2026-10-26 前）

- 改契约、改需求：直接提 PR，站会过目，组长批准即行。

## 冻结后（10/26 起）

1. 开 Issue，挂 `change` 标签，写明变更与缘由；
2. 组长批准（站会或群内书面）；
3. `CHANGELOG.md` 记一行：日期 / 变更 / 缘由 / 关联需求；
4. 才可动代码。**绕过此流程的改动不作数，一律回滚。**

## 铁律

- 变更日志即本课「过程证据」，评审与视频都要点它——每次必须当场记，不许补记。
- 需求变更先改 SRS（带 ID），再改代码；代码与文档不同步的 PR 不 merge。
