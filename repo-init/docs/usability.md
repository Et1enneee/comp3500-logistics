## 测量起止定义
- U‑01 创建订单：起点 = 点击新建订单进入流程；终点 = 订单创建成功页面展示
- U‑02 查询运单轨迹：起点 = 进入运单查询页；终点 = 轨迹完整展示
- U‑03 员工确认/拣货/发货：每个操作独立计数；起点 = 打开订单详情准备操作；终点 = 操作提交、页面状态刷新；仅统计功能按钮点击
- U‑04 状态文案核对：起点 = 订单状态变更页面刷新；终点 = 读取页面状态栏文字，与状态机词表比对
- U‑05 预警列表加载：起点 = 跳转进入预警列表页面；终点 = 首屏预警内容全部渲染完成
